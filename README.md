## Overview

ArtPint is a compact desktop vector graphics workspace for producing illustrations and game assets. Built with Electron, it delivers a cross-platform experience for Windows and Linux and concentrates on everyday drawing, project organization, and asset export tasks.

Alongside standard vector editing, ArtPint provides AI-assisted design workflows, semantic tagging, and structured package integration. CraftBridge connectivity, JSON-based projects, and the dedicated Icon Workshop help take creative work from an initial idea to an organized, reusable export.

---

## Capabilities

- Draw illustrations with vector-based tools.
- Arrange detailed compositions using the layers panel.
- Attach semantic tags for structured asset handling.
- Create icon-oriented designs in the Icon Workshop.
- Save editable projects to JSON and load them again later.
- Produce final assets in SVG or PNG format.
- Integrate AI-assisted design processes through structured packages.
- Connect the application to the wider suite through the CraftBridge control channel.
- Restrict project operations to the designated workspace with the workspace path fence.

## Working with ArtPint

The following sequence represents a common project flow:

1. Start the Electron desktop application.
2. Begin a vector illustration or load an existing JSON project.
3. Divide and manage the artwork with layers.
4. Add semantic tags wherever structured asset identification is needed.
5. Open the Icon Workshop for icon-specific work.
6. Use the structured package integration or CraftBridge channel to connect supported AI-assisted workflows.
7. Save the editable project in JSON format.
8. Export the finished work as SVG or PNG.

When working on workspace-based projects, place source material and generated assets within the intended workspace. This allows the workspace path fence to apply correctly.

### Does ArtPint run on Windows and Linux?

### Which export and project formats are available?

Project content is contained in JSON project files. Configuration files shipped with the repository or application package may also determine integration and workspace behavior.

### What can I check when an integration is not available?

### How should I troubleshoot a failed export?

Make sure the project has been saved, the destination workspace allows writing, and the chosen format is supported. If the problem remains, reopen the JSON project and attempt the export again.
